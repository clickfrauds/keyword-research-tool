Strategy Notes

Since the four ad groups map to four already-live pages, keywords were siloed strictly by which page's offer actually matches the query — the huge volume of generic Semrush/Ahrefs/keyword-tool searches was excluded as it doesn't match any live white-label service. High-CPC, single-intent groups (Google Ads Automation, Click Fraud, SEO Reseller) were set to exact for efficiency, while the broader Static Website Builds theme stays on phrase for discovery.
